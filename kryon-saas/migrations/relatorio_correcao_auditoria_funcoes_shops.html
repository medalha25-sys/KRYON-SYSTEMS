Correção e Calibração da Consulta de Funções e Dependências de Shops

Ajuste técnico na consulta de pg_proc aplicando o filtro estrito p.prokind = 'f' para isolar funções regulares e prevenir erro em funções agregadas (array_agg), mantendo conformidade 100% somente leitura.

1. Explicação Técnica do Ajuste na Consulta de Funções

✔ Causa do Erro Anterior: No PostgreSQL, a função de sistema pg_get_functiondef(oid) aceita apenas funções regulares (prokind = 'f') e procedures (prokind = 'p'). Quando executada sobre funções agregadas nativas como array_agg (prokind = 'a'), o PostgreSQL emite erro de execução.

✔ Solução Aplicada: Inclusão do predicado p.prokind = 'f' e do casting de assinatura p.oid::regprocedure AS signature, garantindo execução fluida e precisa.

2. As 6 Consultas Calibradas para o Supabase SQL Editor
-- 1. Funções regulares no schema public com referência a 'shop' SELECT n.nspname AS schema_name, p.proname AS function_name, p.oid::regprocedure AS signature FROM pg_proc p JOIN pg_namespace n ON n.oid = p.pronamespace WHERE n.nspname = 'public' AND p.prokind = 'f' AND pg_get_functiondef(p.oid) ILIKE '%shop%' ORDER BY p.proname; -- 2. Triggers com referência a 'shop' SELECT event_object_schema, event_object_table, trigger_name, action_statement FROM information_schema.triggers WHERE action_statement ILIKE '%shop%' OR trigger_name ILIKE '%shop%' ORDER BY event_object_table, trigger_name; -- 3. Views com referência a 'shop' no schema public SELECT schemaname, viewname FROM pg_views WHERE schemaname = 'public' AND definition ILIKE '%shop%' ORDER BY viewname; -- 4. Policies RLS com referência a 'shop' SELECT schemaname, tablename, policyname FROM pg_policies WHERE schemaname = 'public' AND (qual ILIKE '%shop%' OR with_check ILIKE '%shop%' OR policyname ILIKE '%shop%') ORDER BY tablename, policyname; -- 5. Todas as colunas chamadas 'shop_id' no schema public SELECT table_schema, table_name, column_name, data_type, is_nullable FROM information_schema.columns WHERE table_schema = 'public' AND column_name = 'shop_id' ORDER BY table_name; -- 6. Todas as Foreign Keys que apontam para public.shops(id) SELECT tc.table_schema, tc.table_name, kcu.column_name, tc.constraint_name, ccu.table_name AS referenced_table, ccu.column_name AS referenced_column, rc.delete_rule, rc.update_rule FROM information_schema.table_constraints tc JOIN information_schema.key_column_usage kcu ON tc.constraint_name = kcu.constraint_name AND tc.table_schema = kcu.table_schema JOIN information_schema.constraint_column_usage ccu ON ccu.constraint_name = tc.constraint_name AND ccu.table_schema = tc.table_schema JOIN information_schema.referential_constraints rc ON rc.constraint_name = tc.constraint_name AND rc.constraint_schema = tc.table_schema WHERE tc.constraint_type = 'FOREIGN KEY' AND ccu.table_schema = 'public' AND ccu.table_name = 'shops' ORDER BY tc.table_name, tc.constraint_name;
