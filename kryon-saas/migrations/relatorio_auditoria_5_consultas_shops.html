Auditoria Estrutural Individualizada: Funções, Triggers, Views, Policies e Colunas de Shops

Mapeamento das dependências no catálogo do PostgreSQL para identificação prévia de qualquer acoplamento antes de decisões estruturais, em estrito modo somente leitura.

1. Contexto das 14 FKs Mapeadas

• Evidência Confirmada: A consulta anterior identificou 14 Foreign Keys apontando para public.shops(id), incluindo 4 tabelas legadas prefixadas com lava_rapido_* (ex: lava_rapido_bookings, lava_rapido_orders, lava_rapido_services, lava_rapido_vehicles) originárias da modelagem inicial de 2024.

• Diretriz de Segurança: Nenhuma Foreign Key, coluna ou tabela será alterada nesta etapa. O objetivo é única e exclusivamente mapear todas as amarras no PostgreSQL.

2. As 5 Consultas Individuais Prontas para o Supabase SQL Editor

Consulta 1: Funções regulares no schema public com 'shop'

SELECT n.nspname AS schema_name, p.proname AS function_name, p.oid::regprocedure AS signature FROM pg_proc p JOIN pg_namespace n ON n.oid = p.pronamespace WHERE n.nspname = 'public' AND p.prokind = 'f' AND pg_get_functiondef(p.oid) ILIKE '%shop%' ORDER BY p.proname;

Consulta 2: Triggers com referência a 'shop'

SELECT event_object_schema, event_object_table, trigger_name, action_statement FROM information_schema.triggers WHERE action_statement ILIKE '%shop%' OR trigger_name ILIKE '%shop%' ORDER BY event_object_table, trigger_name;

Consulta 3: Views com referência a 'shop'

SELECT schemaname, viewname FROM pg_views WHERE schemaname = 'public' AND definition ILIKE '%shop%' ORDER BY viewname;

Consulta 4: Policies RLS com referência a 'shop'

SELECT schemaname, tablename, policyname FROM pg_policies WHERE schemaname = 'public' AND (qual ILIKE '%shop%' OR with_check ILIKE '%shop%' OR policyname ILIKE '%shop%') ORDER BY tablename, policyname;

Consulta 5: Todas as colunas chamadas 'shop_id' no schema public

SELECT table_schema, table_name, column_name, data_type, is_nullable FROM information_schema.columns WHERE table_schema = 'public' AND column_name = 'shop_id' ORDER BY table_name;
