Escopo Exclusivo: Setup e Teardown.

• Cria identidades descartáveis no auth.users.

• Cria as organizações A e B e vincula membros.

🟣 clientB (Bearer JWT de USER_B)

Escopo: Testes da Empresa B.

• Login via signInWithPassword.

• Executa queries HTTP com cabeçalho JWT real de B.
