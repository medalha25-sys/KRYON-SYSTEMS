🔍 EVIDÊNCIA: TENANTS É BASE TABLE

Confirmação Estrutural: Relação public.tenants é uma Tabela Física

Evidência Retornada: categoria: 8. TIPO DE RELACAO TENANTS | relname: tenants | relation_type: BASE TABLE

1. Conclusão Técnica sobre public.tenants

✔ Descoberta: A tabela public.tenants existe fisicamente no banco como BASE TABLE herdada do schema legada (em vez de uma VIEW baseada em public.organizations).

✔ Explicação do Erro 23503: A foreign key profiles_tenant_id_fkey em public.profiles aponta para a tabela física public.tenants(id). Quando o trigger do V5.1 atualizou profiles.tenant_id com o ID de organizations, o PostgreSQL barrou porque o ID não constava na tabela tenants.

2. Consulta Unificada para Visualizar Todas as Evidências em 1 Tela
SELECT 
    '1. PROFILES FK' AS diagnostico,
    tc.constraint_name AS objeto,
    kcu.column_name || ' -> ' || ccu.table_name || '(' || ccu.column_name || ')' AS detalhe
FROM information_schema.table_constraints tc 
JOIN information_schema.key_column_usage kcu ON tc.constraint_name = kcu.constraint_name
JOIN information_schema.constraint_column_usage ccu ON ccu.constraint_name = tc.constraint_name
WHERE tc.table_name = 'profiles' AND tc.constraint_type = 'FOREIGN KEY'
UNION ALL
SELECT '2. CONTAGEM', 'tenants', COUNT(*)::text || ' linhas' FROM public.tenants
UNION ALL
SELECT '2. CONTAGEM', 'organizations', COUNT(*)::text || ' linhas' FROM public.organizations
UNION ALL
SELECT '2. CONTAGEM', 'profiles', COUNT(*)::text || ' perfis' FROM public.profiles;
